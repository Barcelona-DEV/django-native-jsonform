# Changelog

The canonical changelog is maintained in
[`CHANGELOG.md`](https://github.com/Barcelona-DEV/django-native-jsonform/blob/main/CHANGELOG.md).

## 0.1.0 — 2026-08-19

Initial standalone release of the native JSON Schema to Django form engine,
including registries, overrides, dynamic context, admin integration, nested
arrays, discriminated unions, sparse value preservation, and path-aware
validation.
